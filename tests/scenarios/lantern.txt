# lantern: the fifth reef, the next goal past the budget-5 wall (#33).
#
# Rides a single founding rock straight to lantern's own unlock (score
# 100,000) — a placed reef sheds detritus from the moment it drops, so the
# flat output alone gets there with no housing to fill along the way, and no
# budget-5 sea to compose first. Then builds one lantern sea (a center reef
# and an edge reef, both filled) for the bulk of the picture, and a second,
# lantern-only budget-5 sea at the very end for the sprite-cap ceiling.
#
#   cargo run --example capture -- tests/scenarios/lantern.txt
#
# Values are raw engine integers, so 100000000000 is score 100,000. Waits are
# compressed simulation time, and a buy key is a no-op while the species is
# unaffordable or already housed — so a long wait then one sweep of 1/2/3/4
# fills a sea, and a repeat sweep costs nothing.

resize 100x30              # the playable size: the HUD and every key live here
key enter                  # the founding rock on the mid-floor slot
key s
expect started true
expect reefs == 1

# --- straight to lantern's own unlock, riding the founding rock alone -----
# No purchases: a placed reef sheds from the moment it is placed, so the flat
# output (rock: 3 * MICRO/tick, 70% of it collectable after recycling) reaches
# 100,000 on its own — no budget rebuild needed along the way.
wait 48000000
expect score >= 100000000000   # lantern is unlocked
expect score <= 105000000000   # comfortably past it, not by a wild margin

# --- the lantern sea: a center reef and an edge reef, both filled ---------
key n
key y
key up                     # the kind cycle walks the manifest, and the four
key up                     # kinds before the lantern all unlock below it — so
key up                     # four steps forward always land on the lantern,
key up                     # whatever unlocks after it (#23's lagoon does)
capture ghost               # the ghost's shape names the kind; its color cannot
key enter                  # drop it on the mid-floor slot (default cursor 4)
key right
key right
key right
key right                  # slot 8: the pane's right edge
key enter                  # a second lantern reef there
key s
