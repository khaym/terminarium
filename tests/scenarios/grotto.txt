# grotto: the fourth reef, from its unlock to a sea full of shrimp.
#
# Plays the story of #28 — found a sea and ride it to score 40,000, rebuild on
# the grotto, buy every tier to its housing, then look at that sea in all four
# lights and in both panes. Ends past the budget-5 wall with a rock beside the
# grotto, the pair that shares a body color.
#
#   cargo run --example capture -- tests/scenarios/grotto.txt
#
# Values are raw engine integers, so 40000000000 is score 40,000. Waits are
# compressed simulation time, and a buy key is a no-op while the species is
# unaffordable or already housed — so a long wait then one sweep of 1/2/3/4 fills
# a sea, and a repeat sweep costs nothing.

resize 100x30              # the playable size: the HUD and every key live here
key enter                  # the founding rock on the mid-floor slot
key s
expect started true
expect reefs == 1

# --- the climb to the grotto's unlock -------------------------------------
wait 2000000               # a bare reef sheds slowly: ~2 score/s
key 1
key 1
key 1
key 1
key 2
key 2
key 2
key 3
key 3
key 4
wait 2000000
key 1
key 1
key 1
key 1
key 2
key 2
key 2
key 3
key 3
key 4                      # the founding sea is now full: [4, 3, 2, 1]
wait 3100000               # a filled rock sea makes ~10.6 score/s
expect score >= 40000000000   # the grotto is unlocked
expect score <= 74999999999   # and the budget-5 wall is still ahead

# --- composing the grotto sea ---------------------------------------------
key n
key y                      # a new sea: the score (and its unlocks) survives
phase day
key up                     # the kind cycle walks the manifest, and the three
key up                     # kinds before the grotto (rock, coral, kelp) all
key up                     # unlock below it — so three steps forward always
                           # land on the grotto, whatever unlocks after it
capture ghost              # the ghost's shape names the kind; its color cannot
key enter                  # drop it on the mid-floor slot
key s
expect started true
expect reefs == 1
